# ROADMAP — DroneFlames Reborn

Наш принцип: **новый функционал не должен ломать фреймтайм**. Каждая версия проходит
FPS-бюджет на стресс-сцене `--bench` перед релизом.

## v1.0 — «Возрождение» (текущая)

- [x] Аудит горячих путей симуляции (perf_sys + headless bench)
- [x] `wd_exit`: мемоизация поиска границы (×25 к стоимости `_wd_tick`)
- [x] `_wd_tick`: бакеты юнитов по странам, O(1)-очередь, конвейер ключей
- [x] `_centre`: кластеризация O(n) вместо O(n²)
- [x] ИИ артиллерии: пространственная сетка 45px
- [x] `_acquire`: стаггеринг поиска целей по чётности id
- [x] Рендер по умолчанию: gl_compatibility
- [x] Тонкая инструментация army/operations
- [x] Ребрендинг, новое главное меню (бейдж REBORN), автообновление на наш репозиторий
